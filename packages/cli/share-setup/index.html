One-time setup code


1. Save the private credentials on the Studio
The command saves a private 0600 file at ~/.foundation/share-service/github-app.json, outside your repositories. It never prints the key. Treat the code as a private credential until finish runs. Share it only with your trusted setup agent.


2. Install on your repository
Choose Only select repositories → honeybeehq/foundation.
Install GitHub App →
The finish command prints the exact install link. If you renamed the App on GitHub, use that link.


3. Check the connection
foundation share github-app check --user trmdy
Checks repository permission metadata and confirms the App cannot receive Contents permission. Public repository contents remain public.
