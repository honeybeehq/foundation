Apiary — Tracks pane · Flow View

A track is an expected sequence of steps clipped onto one agent. The pane is a rail of definitions on the left and the selected definition drawn as a flow on a canvas — live while an agent is attached, and as a diff while a sidecar proposal is pending.
Flow View · brought up to date with Classic TracksPane (apiary proto/design-to-code-tracks) · supersedes the list-based spine layout
THE RAIL — DEFINITIONS One row per definition. The second line is its shape: step count, then the type mix. Live state does not live on the row — only a running dot for the track an agent is on.
THE CANVAS — ONE FLOW Steps are cards on a dot grid, joined by hairlines. Parallel lanes sit side by side inside a branch frame; a review gate's denied arm drops to the right and rejoins the spine.
LIVE REGISTER While attached, the flow is read-only: done steps fade back with a check, the current step lifts with a running dot, upcoming steps wait as hollow rings. The canvas pans; steps past the fold are still there.
EXCEPTIONS Deviation is counted quietly in the footer — a waiting dot and “1 exception” — and opens on click. It is visible, never punished.
No honey in the live register: it is spent once per pane, on accepting a proposal or on New track.
NO BLUEPRINT LAYER A starter-template grid is the obvious empty state and the wrong one: a template layer is an explicit non-goal. So the affordance is the real verb — write one down.
TRACK ≠ MACHINE A machine is a canvas with triggers built in, holding many jobs, alive for years. A track is the small thing: one agent, one expected sequence. Tracks work on agents inside machines, but neither feature needs the other.
THE SAME FRAME Rail, canvas and sidecar rail are all still there with zero tracks, so the first definition appears in place rather than replacing a splash screen.
ONE PIXEL MOMENT Art tokens are declared separately from chrome tokens on purpose: the bee may be vivid, the UI palette stays restrained, and the two never bleed into each other.
Honey once per pane: New track here, Accept on a proposal. Never two at once.
